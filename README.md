# battosai portfolio

This repository contains the `battosai portfolio` project: a cyberpunk-inspired portfolio wireframe built in plain HTML and CSS to showcase product management, design system, and digital product capabilities.

## Project Overview

- **Project name:** battosai portfolio
- **Main file:** `Wireframe v2.html`
- **Purpose:** showcase user ability to present a professional personal brand, highlight product leadership, and demonstrate design system and project delivery experience.
- **Style:** full-viewport wireframe sections, bold cyberpunk visual language, responsive layout, and mobile hamburger navigation.

## Key Sections

1. **Hero**
   - Animated video background with scanline effect
   - Large name and role statement for Tito Tamaro
   - Action buttons for GitHub, WhatsApp, and CV download
   - Mobile-friendly hamburger menu for navigation

2. **About**
   - Portrait and punchy professional summary
   - Senior product manager experience across automotive, tech, and manufacturing
   - Strong focus on business strategy, stakeholder alignment, and execution

3. **Skills**
   - Organized categories for project management, stakeholder management, methodologies, and technical tools
   - Highlights Azure, AWS, JIRA, Python, PowerBI, and product strategy skills

4. **Journey**
   - Career timeline with key roles from 2017 to present
   - Includes current product & project management role at Berlian Sistem Informasi
   - Shows leadership in enterprise digital transformation, AI, and system delivery

5. **Projects**
   - Primary case study for digital spare parts catalog
   - New second project: **Berlian Sistem Informasi Design System**
   - Includes a dedicated showcase page at `project-02-bsi-design-system.html`

6. **Contact**
   - CTA grid linking to GitHub, WhatsApp, and downloadable CV
   - Clear call-to-action for connection and follow-up
