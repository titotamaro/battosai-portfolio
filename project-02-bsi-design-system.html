This dedicated showcase page highlights the system design work created for Berlian Sistem Informasi (BSI), with a focus on reusable components, consistent interaction patterns, and a scalable governance model for BSI’s enterprise applications.

Project summary

Built the BSI design system to standardize UI behavior, visual language, and component usage across the organization. The effort included system architecture, component definitions, accessibility guardrails, and handoffs to product and engineering teams.
