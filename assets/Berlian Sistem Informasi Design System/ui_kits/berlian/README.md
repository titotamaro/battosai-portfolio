# Berlian Sistem Informasi — UI Kit

A high-fidelity interactive prototype of the PT Berlian Sistem Informasi corporate web presence and internal dashboard.

## Screens

1. **Homepage** — Hero, services grid, stats, CTA
2. **Services** — IT solutions listing
3. **Dashboard** — Internal enterprise portal (after login)
4. **Contact** — Contact form

## Components

- `Components.jsx` — Navbar, Footer, Hero, ServiceCard, StatBar, Button, Badge, FormField, Sidebar, DashCard

## Usage

Open `index.html` in a browser. Click navigation items to switch between screens.

## Design Notes

- Colors from `colors_and_type.css`
- Font: Barlow Condensed (display), Barlow (body) via Google Fonts
- Logo assets from `../../assets/`
- Icons: Lucide (CDN)
